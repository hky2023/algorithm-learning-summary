## <span style="color:green"> 这道题目一开始想的时候就有一点困难.</span>
想到了一点困难的。
* 1个数的数组，那么不用判断就是好数组
* 3个数的数组，也不用判断也是好数组
* 5个数的数组，需要判断进行操作的顺序对于其的影响
---
例如
$[3, 1, 1, 2, 1]$
* 左边3个先进行操作，可以完成转化
* 右边三个先进行操作，不可以完成转化
* 中间三个先进行操作，可以完成转化
---
> 因此能否完成操作也和操作进行的顺序有关

## <span style="color:green">现在试想出规律</span>

例如 $[a1, a2, a3, a4, a5]$

### <span style="color:rgb(11,133,233)">我们大胆假设结论:</span>
> $a1 + a3 + a5 - a2 - a4 > 0$ 可以得出一定存在一个操作序列使得数组变成一个数

证明：

已知：$a1 + a3 + a5 - a2 - a4 > 0$

* if $a1 + a3 - a2 > 0$ and $a1 + a3 + a5 - a2 -a4 > 0$ then 我们可以先左后右完成操作
  
* if $a1 + a3 - a2 <= 0$ , so $a5 - a4 > 0$, so $a3 + a5 - a4 > 0$, then 我们可以先右后左

* if $a2 + a4 - a3 > 0$ and $a1+a3+a5-a2-a4>0$, so 我们可以先中

* if $a2 + a4 - a3 <= 0$, so $a3 >= a2, a3 >=a4$, because $a1>0,a2>0,a3>0,a4>0,a5>0$, so $a1 +a3 -a2>0, a3 + a5 - a4>0$ ,then 我们可以先左再右，也可以先右再左。

所以：$a1+a3+a5-a2-a4>0$, 可以得出一定存在一个操作序列使得数组变成一个数

> 我们大胆假设：题目变成了判断，元素个数为奇数，奇数位之和 >= 偶数位之和的子数组个数
